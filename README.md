## **Project Overview**
This project is a **responsive authentication system** styled using **Bootstrap 5** and **custom CSS**.  
It includes **Login, Registration, Forgot Password, Reset Password, and Dashboard pages**.  
The system is fully functional for demo purposes using **HTML form redirects**, without JavaScript.

---

## **Features**
- Fully styled using **Bootstrap 5** components (cards, forms, buttons, navbar)
- **Custom CSS** for gradient background, card shadows, hover effects, smooth transitions
- **Responsive design** for Mobile, Tablet, Laptop, and Desktop
- Navigation between pages using **HTML form actions and links**
- Professional dashboard layout with cards and logout button

## Instructions to Open
1. Open `index.html` in a browser.
2. Navigate between pages using buttons and links.
   - Login → Dashboard
   - Register → Login
   - Forgot Password → Reset Password → Login
   - Dashboard Logout → Login
